Make music

Choose a track, then edit its notes or mix. Changes save automatically. Audition plays the latest arrangement.

Space: play / pause · Home: return to start
Ctrl+Z: undo · Ctrl+Shift+Z: redo
Piano roll: double-click to add; drag to move; drag a note’s right edge to resize.
Arrows: move notes · Shift+Left/Right: resize · Shift+Up/Down: octave
Shift-click: select multiple notes · Delete: remove
Ctrl+A: select all · Ctrl+D: duplicate · Ctrl+C / X / V: copy / cut / paste
Escape: clear selection or close this help

Multiple Solo buttons play together. Mute always wins. Live mix previews fader changes; Audition includes the finished effects.
